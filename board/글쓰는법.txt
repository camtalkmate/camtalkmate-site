[게시판에 글 올리는 법 — 관리자 페이지]

1. 브라우저(휴대폰도 됨)에서  https://내도메인/admin  접속 → 관리자 로그인 → "게시판" 메뉴 → GitHub 로그인
2. 왼쪽 "게시판 글" → 오른쪽 위 "새 글" 클릭
3. 제목, 날짜, 검색 결과 요약, 키워드, 주소용 영문 이름, 본문 입력
   - 본문은 워드처럼 씁니다. 소제목은 '제목 2', 요약은 목록, 강조는 굵게.
   - 사진은 본문 편집창의 + 버튼 → 이미지 로 넣습니다.
4. 오른쪽 위 "발행" 클릭 → 1~2분 뒤 사이트 게시판에 자동으로 올라갑니다.
   - "임시 저장"에 체크하고 발행하면 저장만 되고 사이트에는 안 보입니다. 나중에 체크를 풀고 다시 발행하면 공개됩니다.
5. 글을 고칠 때는 목록에서 글을 눌러 수정 → 발행.

* 공백 빼고 1,300자 이상이 검색에 유리합니다.
* 금지: '통화 단가 배수' 언급, 수익 '보장' 표현, 실제 인물 후기 창작.
* 새 글이 네이버에 빨리 뜨게 하려면: 서치어드바이저 > 요청 > 웹 페이지 수집 에 글 주소 입력.

(파일로 직접 쓰고 싶다면 board/_posts/ 폴더에 .md 파일을 만들어 GitHub에 올려도 됩니다. 형식은 기존 글 파일을 참고.)
